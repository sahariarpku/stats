Handwriting fonts used by the website and the interactive pictures, stored here so nothing loads from outside.

- Caveat Brush (headings), Patrick Hand (body text), Caveat Bold (margin notes)
- All three are licensed under the SIL Open Font License 1.1. See the OFL-*.txt files.
- Obtained from the Fontsource npm packages `@fontsource/caveat-brush`, `@fontsource/patrick-hand` and `@fontsource/caveat` (Latin subset only).

Motion is driven by anime.js 3.2.2 (MIT), stored in assets/vendor/anime.min.js.
