# Animations

Every animation is a single HTML file. Open it in any browser, or click the link if GitHub Pages is on for this repository. Each one has sliders you can drag, works on a phone, and follows your light or dark theme.

| [The parameter stands still. The statistic wanders.](stages/00-start-here/03-population-vs-sample/visuals/sampling-error.html) | 0.3 Population vs Sample | Each grey dot is one person in a population of 200 (heights in cm). Draw a random sample and compare its average to the true average. |

| [Build a box plot](stages/01-describing-data/02-range-quartiles-box-plot/visuals/box-plot.html) | 1.2 Range, Quartiles and the Box Plot | Each dot is one exam score. Drag a dot (or use the arrow keys) and watch the five numbers and the box plot update. Then press "Add an extreme value". |
