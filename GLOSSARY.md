# Glossary

Every key term from the lessons, in one alphabetical list. Each entry links to the lesson that teaches it.

| Term | Meaning | Lesson |
|---|---|---|
| **Adjusted R²** | R² reduced for the number of predictors | [8.3](stages/08-relationships/03-r-squared-and-residuals/docs/en.md) |
| **Alternative H₁** | The effect or difference we look for evidence of | [6.1](stages/06-hypothesis-testing/01-hypotheses/docs/en.md) |
| **ANOVA** | A test that compares three or more means by comparing between-group to within-group variation | [7.2](stages/07-comparing-groups/02-anova/docs/en.md) |

| **Bin** | A range of values that gets counted together | [1.4](stages/01-describing-data/04-histograms-shape-skewness/docs/en.md) |
| **Binomial** | The *count* of successes in n independent trials with constant p | [3.2](stages/03-distributions/02-binomial/docs/en.md) |
| **Blinding** | Hiding the assignment from participants (single) and measurers (double) | [9.1](stages/09-going-further/01-study-design/docs/en.md) |

| **Bootstrap sample** | A resample of size n drawn *with replacement from your sample* | [4.5](stages/04-sampling/05-bootstrap/docs/en.md) |

| **Categorical** | Data that place individuals in groups. It may be written with digits (ZIP codes) | [0.2](stages/00-start-here/02-types-of-data/docs/en.md) |
| **CDF** | F(x) = P(X ≤ x), the running total from the left | [3.1](stages/03-distributions/01-random-variables/docs/en.md) |
| **Central Limit Theorem** | Sample **means** (and sums) become approximately normal as n grows | [4.3](stages/04-sampling/03-central-limit-theorem/docs/en.md) |
| **CI for the difference** | The plausible range for μ₁ − μ₂, which shows the size and direction of the gap | [6.6](stages/06-hypothesis-testing/06-two-sample-t-test/docs/en.md) |
| **Coefficient of variation** | SD ÷ mean as a percentage, for comparing relative spread | [1.3](stages/01-describing-data/03-variance-standard-deviation/docs/en.md) |
| **Cohen's d** | The difference in means in pooled-SD units | [6.8](stages/06-hypothesis-testing/08-effect-size/docs/en.md) |
| **Combination** | A selection where **order doesn't** matter | [2.2](stages/02-probability/02-counting/docs/en.md) |
| **Complement** | Everything in the sample space that is *not* in the event | [2.1](stages/02-probability/01-basic-probability/docs/en.md) |
| **Conditional probability** | P(A \| B): the probability of A **inside the world where B happened** | [2.4](stages/02-probability/04-conditional-probability/docs/en.md) |
| **Conditional probability P(B | A)** | The probability of B *given that A has already happened* | [2.3](stages/02-probability/03-or-and-rules/docs/en.md) |
| **Confidence interval** | A range built by a method that captures the true value a stated percentage of the time | [5.1](stages/05-confidence-intervals/01-confidence-intervals/docs/en.md) |
| **Confidence interval (mean)** | Range for the mean of y at a given x | [8.3](stages/08-relationships/03-r-squared-and-residuals/docs/en.md) |
| **Confidence level** | The long-run success rate of the *method* | [5.1](stages/05-confidence-intervals/01-confidence-intervals/docs/en.md) |
| **Confounder** | Something that affects both variables and creates a misleading correlation | [8.1](stages/08-relationships/01-correlation/docs/en.md) |
| **Confusion matrix** | Counts of true/false positives and negatives at a chosen cut-off | [8.5](stages/08-relationships/05-logistic-regression/docs/en.md) |
| **Conjugate prior** | A prior whose posterior has the same form (Beta for proportions) | [9.3](stages/09-going-further/03-bayesian-vs-frequentist/docs/en.md) |
| **Contingency table** | A table of counts for two categorical variables | [7.1](stages/07-comparing-groups/01-chi-square-tests/docs/en.md) |
| **Continuity correction** | Shifting limits by 0.5 because whole-number bars have width 1 | [3.5](stages/03-distributions/05-normal-approximation/docs/en.md) |
| **Continuous** | Measured values, with infinitely many possibilities in any range | [0.2](stages/00-start-here/02-types-of-data/docs/en.md) |
| **Control group** | A group that receives no treatment or the standard one | [9.1](stages/09-going-further/01-study-design/docs/en.md) |
| **Correlation vs causation** | A link in the data does not show that one variable changes the other | [8.1](stages/08-relationships/01-correlation/docs/en.md) |
| **Coverage** | The actual fraction of intervals that contain the truth | [5.3](stages/05-confidence-intervals/03-ci-for-proportion/docs/en.md) |
| **Cramér's V** | √[χ²/(N(k−1))]: an effect size between 0 and 1 | [7.1](stages/07-comparing-groups/01-chi-square-tests/docs/en.md) |
| **Credible interval** | An interval containing the parameter with the stated probability, given the data and prior | [9.3](stages/09-going-further/03-bayesian-vs-frequentist/docs/en.md) |
| **Critical value** | The test-statistic value that marks the edge of the rejection region | [6.2](stages/06-hypothesis-testing/02-p-values-and-significance/docs/en.md) |
| **Critical value z\*** | The z that leaves the right tail probability for your confidence level | [5.1](stages/05-confidence-intervals/01-confidence-intervals/docs/en.md) |
| **Degrees of freedom** | How many values are free to vary once the mean is fixed (n − 1 here) | [1.3](stages/01-describing-data/03-variance-standard-deviation/docs/en.md) |
| **Descriptive** | Exact summaries of the data you hold | [0.1](stages/00-start-here/01-what-is-statistics/docs/en.md) |
| **Deviation** | A value minus the mean. It can be negative | [1.3](stages/01-describing-data/03-variance-standard-deviation/docs/en.md) |
| **df** | Degrees of freedom for the t curve: n − 1 here | [6.5](stages/06-hypothesis-testing/05-one-sample-t-test/docs/en.md) |
| **Difference d** | After − before (or the reverse) for each pair, the new variable analysed | [6.7](stages/06-hypothesis-testing/07-paired-t-test/docs/en.md) |
| **Discrete** | Counted values, with nothing in between | [0.2](stages/00-start-here/02-types-of-data/docs/en.md) |
| **Distribution** | The full list (or curve) of how probability is spread over the values | [3.1](stages/03-distributions/01-random-variables/docs/en.md) |
| **Dummy variable** | A 0/1 variable that represents a category | [8.4](stages/08-relationships/04-multiple-regression/docs/en.md) |

| **Empirical rule** | 68-95-99.7 holds for (roughly) normal data only | [3.4](stages/03-distributions/04-normal-distribution/docs/en.md) |
| **Event** | A subset of the sample space | [2.1](stages/02-probability/01-basic-probability/docs/en.md) |

| **Expected value E(X)** | The long-run average per trial, which may be impossible on a single trial | [2.6](stages/02-probability/06-expected-value-and-lln/docs/en.md) |
| **Experiment / RCT** | Researchers assign treatments, with random assignment in an RCT | [9.1](stages/09-going-further/01-study-design/docs/en.md) |
