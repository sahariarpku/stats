# Cheat sheet: Population vs sample

| | Population | Sample |
|---|---|---|
| Size | N | n |
| Number is a | **parameter** (fixed, usually unknown) | **statistic** (known, varies) |
| Mean | μ | x̄ |
| SD | σ (÷ N) | s (÷ n − 1) |
| Variance | σ² | s² |
| Proportion | p | p̂ |
| Correlation | ρ | r |

**P**opulation → **P**arameter → Greek letters. **S**ample → **S**tatistic → Roman letters.

**Sampling error** = statistic − parameter. Normal, shrinks with larger n.
**Bias** = a systematic tilt from *how* you sampled. More data does not fix it.
