# Cheat sheet: What is statistics?

**Statistics** = collect, organise, analyse and interpret data to make decisions, *and say how sure you are*.

| | Descriptive | Inferential |
|---|---|---|
| Job | Summarise data you have | Generalise from a sample to a population |
| Tools | Mean, SD, charts | Confidence intervals, hypothesis tests |
| Result | Exact | Uncertain, with stated confidence |

**One-question test:** *Am I talking only about the numbers I measured, or about a bigger group I did not?* Only measured → descriptive. Bigger group → inferential.

**The cycle:** Ask → Collect → Describe → Infer.

**Trap:** Skipping "Describe". Always look at the data before concluding anything.
