# Stage 0: Start Here

> Get the big picture: what statistics is, what kinds of data exist, and why a sample can speak for a population.

| Lesson | What it teaches | Time |
|---|---|---|
| [0.1 What Is Statistics?](01-what-is-statistics/docs/en.md) | Statistics turns piles of numbers into decisions you can defend. | ~15 min |
| [0.2 Types of Data](02-types-of-data/docs/en.md) | The kind of data you hold decides which maths is allowed. | ~25 min |
| [0.3 Population vs Sample](03-population-vs-sample/docs/en.md) | You almost never measure everyone. So learn what a few can tell you about all. | ~25 min |

**Stage time:** about 1 h 05 min across 3 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
