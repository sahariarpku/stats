# Stage 6: Hypothesis Testing

> Run and read z-tests, t-tests, p-values, errors, power and effect sizes, and choose the right test.

| Lesson | What it teaches | Time |
|---|---|---|
| [6.1 The Logic of Hypothesis Testing](01-hypotheses/docs/en.md) | Assume nothing special is going on. Then ask: how surprising is my data under that assumption? | ~40 min |
| [6.2 p-values and Significance](02-p-values-and-significance/docs/en.md) | The p-value measures surprise under the null hypothesis. The significance level α is how much surprise you demand before you reject. | ~45 min |
| [6.3 Errors and Power](03-errors-and-power/docs/en.md) | A test can be wrong in two ways. Power is the chance it finds a real effect. | ~40 min |
| [6.4 z-Tests for Means and Proportions](04-z-tests/docs/en.md) | Your first complete tests. Same six steps every time, with a different test statistic. | ~45 min |
| [6.5 The One-Sample t-Test](05-one-sample-t-test/docs/en.md) | Is the average of a group different from a stated value? The everyday test, built for when σ is unknown. | ~40 min |
| [6.6 The Two-Sample t-Test](06-two-sample-t-test/docs/en.md) | Do two separate groups differ on average? Use Welch's version unless you have a strong reason not to. | ~45 min |
| [6.7 The Paired t-Test](07-paired-t-test/docs/en.md) | When each "before" has its own "after", test the differences. Pairing removes the noise between people. | ~35 min |
| [6.8 Effect Size and Practical Significance](08-effect-size/docs/en.md) | A p-value says an effect probably exists. The effect size says how big it is. You need both. | ~35 min |
| [6.9 Choosing the Right Test](09-choosing-a-test/docs/en.md) | Four questions pick the test. Answer them in order and the test is usually obvious. | ~30 min |

**Stage time:** about 5 h 55 min across 9 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
