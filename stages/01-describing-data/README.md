# Stage 1: Describing Data

> Summarise any dataset: where it is centred, how spread out it is, and what shape it has.

| Lesson | What it teaches | Time |
|---|---|---|
| [1.1 Mean, Median and Mode](01-mean-median-mode/docs/en.md) | One number to stand for many, and a way to tell when it is lying. | ~25 min |
| [1.2 Range, Quartiles and the Box Plot](02-range-quartiles-box-plot/docs/en.md) | The centre tells you where the data sit. The spread tells you how much to trust that. | ~35 min |
| [1.3 Variance and Standard Deviation](03-variance-standard-deviation/docs/en.md) | Standard deviation is the typical distance from the average. Here is how to build it, one small step at a time. | ~40 min |
| [1.4 Histograms, Shape and Skewness](04-histograms-shape-skewness/docs/en.md) | Numbers summarise. A picture shows what the numbers cannot. | ~35 min |
| [1.5 Z-Scores](05-z-scores/docs/en.md) | A z-score says how many standard deviations a value sits from the mean. It is a common yardstick for anything. | ~30 min |

**Stage time:** about 2 h 45 min across 5 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
