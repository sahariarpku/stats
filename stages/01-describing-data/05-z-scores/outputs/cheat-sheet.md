# Cheat sheet: Z-scores

**z = (x − μ) ÷ σ**  (for a sample, use x̄ and s)  ·  **x = μ + zσ**

| z | Meaning | Share below (normal data) |
|---|---|---|
| −2 | 2 SD below | 2.3% |
| −1 | 1 SD below | 15.9% |
| 0 | the mean | 50% |
| +1 | 1 SD above | 84.1% |
| +2 | 2 SD above | 97.7% |
| +3 | 3 SD above | 99.9% |

**68-95-99.7 rule:** within ±1, ±2, ±3 SD there is about 68%, 95%, 99.7% of the values.

**Standardised data:** mean 0, SD 1, same shape, same ranking.

**Use z to** compare across scales · spot unusual values (|z| > 2 or 3) · look up probabilities (z-table).

**Traps**
1. Percentiles from z need roughly bell-shaped data.
2. |z| > 3 means "investigate", not "delete".
3. Compare z-scores, not raw scores, across different tests.
