# Stage 3: Distributions

> Meet the binomial, Poisson and normal distributions, and know which one fits a situation.

| Lesson | What it teaches | Time |
|---|---|---|
| [3.1 Random Variables and Distributions](01-random-variables/docs/en.md) | A random variable turns an outcome into a number. A distribution says how likely each number is. | ~40 min |
| [3.2 The Binomial Distribution](02-binomial/docs/en.md) | Count the successes in a fixed number of independent yes/no trials. | ~40 min |
| [3.3 The Poisson Distribution](03-poisson/docs/en.md) | Count how many events happen in a fixed stretch of time or space, when you only know the average rate. | ~35 min |
| [3.4 The Normal Distribution](04-normal-distribution/docs/en.md) | The bell curve: two numbers (mean and SD) describe it completely, and areas under it are probabilities. | ~45 min |
| [3.5 Normal Approximation to the Binomial](05-normal-approximation/docs/en.md) | When there are many trials, the binomial bar chart looks like a bell curve. Then a z-table can replace a very long sum. | ~30 min |

**Stage time:** about 3 h 10 min across 5 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
