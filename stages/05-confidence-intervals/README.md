# Stage 5: Confidence Intervals

> Put honest error bars on an estimate of a mean or a proportion.

| Lesson | What it teaches | Time |
|---|---|---|
| [5.1 Confidence Intervals](01-confidence-intervals/docs/en.md) | An honest estimate is a range, not a single number: "probably between here and here". | ~40 min |
| [5.2 The t-Distribution and Intervals for a Mean](02-t-distribution-and-ci-for-mean/docs/en.md) | When you must estimate σ from the data, you pay a small price: a slightly fatter curve called the t-distribution. | ~40 min |
| [5.3 Confidence Intervals for a Proportion](03-ci-for-proportion/docs/en.md) | Polls, defect rates, conversion rates: put an honest range on a percentage. Use the Wilson interval when the sample is small or the rate is extreme. | ~40 min |

**Stage time:** about 2 h 00 min across 3 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
