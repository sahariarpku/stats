# Stage 7: Comparing Groups

> Compare categories (chi-square), three or more means (ANOVA) and skewed data (rank tests).

| Lesson | What it teaches | Time |
|---|---|---|
| [7.1 Chi-Square Tests for Categories](01-chi-square-tests/docs/en.md) | When your data are counts in categories, compare what you *observed* with what you would *expect* if nothing were going on. | ~50 min |
| [7.2 ANOVA: Comparing Three or More Means](02-anova/docs/en.md) | To compare many group means at once, ask one question: are the groups farther apart than the scatter inside each group would explain? | ~60 min |
| [7.3 Rank-Based Tests: When Averages Mislead](03-rank-based-tests/docs/en.md) | Replace each value with its rank (1st smallest, 2nd smallest, ...) and test the ranks. Outliers and odd shapes lose their power to fool you. | ~55 min |

**Stage time:** about 2 h 45 min across 3 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
