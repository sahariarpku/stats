# Stage 8: Relationships

> Measure and model how variables move together: correlation, regression and yes/no outcomes.

| Lesson | What it teaches | Time |
|---|---|---|
| [8.1 Correlation: Do Two Numbers Move Together?](01-correlation/docs/en.md) | Correlation puts "when one goes up, does the other go up too?" on a scale from −1 to +1. It describes a pattern. It never explains one. | ~55 min |
| [8.2 Simple Linear Regression: Drawing the Best Line](02-simple-linear-regression/docs/en.md) | Regression turns "these two things are related" into a line you can use to predict, and tells you how much to trust it. | ~55 min |
| [8.3 R-Squared and Residuals: Is the Line Any Good?](03-r-squared-and-residuals/docs/en.md) | A line is easy to draw and easy to trust too much. R² says how much the line explains. The residuals tell you whether the line is the right kind of model at all. | ~50 min |
| [8.4 Multiple Regression: Many Predictors at Once](04-multiple-regression/docs/en.md) | Real outcomes have more than one cause. Multiple regression puts several predictors in one model and tells you what each adds *after the others are accounted for*. | ~55 min |
| [8.5 Logistic Regression: Predicting Yes or No](05-logistic-regression/docs/en.md) | When the outcome is a yes/no, a straight line breaks. Logistic regression bends it into an S-curve that always stays between 0 and 1 and answers "what is the probability?" | ~55 min |

**Stage time:** about 4 h 30 min across 5 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
