# Stage 2: Probability

> Reason about chance: rules, counting, conditional probability, Bayes' theorem and long-run averages.

| Lesson | What it teaches | Time |
|---|---|---|
| [2.1 Basic Probability](01-basic-probability/docs/en.md) | Probability is a number from 0 to 1 that says how likely something is. Counting outcomes is how you get it. | ~30 min |
| [2.2 Counting: How Many Ways?](02-counting/docs/en.md) | To find a probability you often need to count outcomes. Counting has only three tools. Learn which one to pick. | ~35 min |
| [2.3 Combining Events: OR and AND](03-or-and-rules/docs/en.md) | OR means add (then subtract the overlap). AND means multiply (then ask: does the first event change the second?). | ~40 min |
| [2.4 Conditional Probability](04-conditional-probability/docs/en.md) | "Given that" shrinks the world. Probability is then measured inside the smaller world. | ~40 min |
| [2.5 Bayes' Theorem](05-bayes-theorem/docs/en.md) | A positive test is evidence, not proof. How much evidence depends on how common the thing was to begin with. | ~40 min |
| [2.6 Expected Value and the Law of Large Numbers](06-expected-value-and-lln/docs/en.md) | Expected value is what happens on average. The Law of Large Numbers says averages settle down. Neither says what happens next time. | ~35 min |

**Stage time:** about 3 h 40 min across 6 lessons.

Every lesson folder contains the lesson (`docs/en.md`), runnable code (`code/`), animations (`visuals/`), a quiz (`quiz.json`) and a one-page cheat sheet (`outputs/cheat-sheet.md`).
